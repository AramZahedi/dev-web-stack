## phpMyAdmin signed signon

- `config.user.inc.php` uses `auth_type = 'signon'` with `SignonSession = 'devstack_signon'`; no root credential is stored in PHP config.
- The dashboard button calls `POST /api/v1/services/phpmyadmin/signon`, which returns a 30-second HMAC-signed, single-use URL.
- The token is carried in the URL fragment; `signon.php` reads it, clears the fragment with `history.replaceState`, and POSTs it once. Server access logs contain only `POST /signon.php`, never the token.
- `signon.php` verifies the signature and expiry, consumes the nonce once, then reads `/run/secrets/root_password` and sets the phpMyAdmin signon session.
- Direct `http://127.0.0.1:8082/` shows the manual signon form; it does not auto-login.
- Replayed, tampered, and expired tokens are rejected.
- The daemon reads the same `signon_key` the container mounts; the 8-worker/E2E key is generated by the PMA preparer/agent. The WSL key and the daemon's UNC path hash matched, and the PMA access log contains **0** token-bearing lines.
- Live browser check passes: dashboard button → no password prompt → `Server: db:3306`; direct access → manual form; replay → rejected.
- No root password or token is written into the PHP config or evidence.
